# アリーナ・サバイバル

題材シリーズ #1。3D 見下ろし型のツインスティック・シューター。
平面のアリーナを移動して射撃し、ウェーブごとに出現する敵を倒す。

## 主に学ぶこと
プロジェクトの土台一式: 立ち上げ手順、ゲームループと固定タイムステップ、合成、イベント / メッセージング、Result / Option、設定ファイルの読み込み。

## 文書
- [設計書](docs/design.md)
- [決定記録](docs/adr/README.md)

## 実行
```sh
cmake --preset debug && cmake --build --preset debug
./build/debug/games/arena-survival/app/arena_app
```
